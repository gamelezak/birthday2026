СЧЁТЧИК ДО ДНЯ РОЖДЕНИЯ — PIXEL ART

Файлы:
- index.html — страница
- styles.css — стили и анимации
- script.js — таймер, звёзды, метеоры и настройка даты
- assets/birthday-bg.png — пиксель-артовый фон с тортом «19»

ЗАПУСК:
1. Открой index.html в браузере.

ДАТА:
Открой script.js и измени:
const DEFAULT_BIRTHDAY = '2026-09-01T00:00';

Также дату можно менять прямо на странице — она сохраняется в localStorage браузера.

ИНТЕРНЕТ:
Шрифт Press Start 2P подключается через Google Fonts. Чтобы сайт полностью работал офлайн,
скачай этот шрифт и подключи локальный файл через @font-face в styles.css.
